☕ Rene’s Coffee House
---

📌 Project Overview

Rene’s Coffee House is a React-based coffee shop web application that allows users to browse coffee products, search items, and manage products through an admin dashboard.
The project demonstrates modern React concepts including components, hooks, context API, routing, and CRUD operations using a mock JSON server.

---

🚀 Features
---

🏠 Home Page
---
Displays a welcome message and overview of the coffee shop


🛍️ Shop Page
---
Displays all coffee products
Dynamic search functionality to filter products by name
Responsive product grid layout


🧑‍💼 Admin Dashboard
---
View all products in inventory
Edit product price (PATCH request)
Delete products (DELETE request)
Real-time updates after changes

➕ Add Product Page
---
Add new coffee products using a form
Sends POST request to JSON server
Automatically updates product list

---

⚙️ Technologies Used
---

React
React Router DOM
Context API
useState & useEffect Hooks
Custom Hooks
JSON Server (mock backend)
Fetch API
CSS Modules
Vitest & React Testing Library

📦 CRUD Operations
---
Create: Add new product (POST)
Read: Fetch and display products (GET)
Update: Edit product price (PATCH)
Delete: Remove product (DELETE)

🧠 Key Concepts Demonstrated
---
Component-based architecture
State management using React Hooks
Global state management with Context API
Custom hook for data fetching
Client-side routing with React Router
Form handling and controlled inputs
API communication using Fetch
Unit testing with Vitest
